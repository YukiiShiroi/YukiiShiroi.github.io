Kanamichi · かな道

Privacy

Last updated 27 October 2026

Kanamichi collects no personal data. There are no accounts, no ads, no analytics and no tracking.

What stays on your device

Your learning progress, settings, your own vocabulary and memory aids are stored only on your device — in the app's storage, or in your browser when you use the web version. You can export it as a backup file or delete it at any time (Settings → Backup → Reset all progress).

Optional sync

If you choose to turn on sync, your progress is saved to a private file (a secret Gist) on your own GitHub account, using a token you create and paste into the app. That file is sent directly between your device and GitHub; it never passes through any server run by Kanamichi's developer, who can't see it. The token is stored only on your device, and you can revoke it on GitHub at any time. GitHub's own privacy statement covers that file.

Network

The app works offline. The only connections it makes are to GitHub's API, and only if you turn on sync. The web version also loads its own files from GitHub Pages, which hosts it.

Children

Kanamichi is suitable for all ages and collects nothing from anyone, including children.
